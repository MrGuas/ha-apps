# WhatsApp puente

![Versión][version-shield] ![amd64][amd64-shield] ![aarch64][aarch64-shield]

Conecta WhatsApp a Home Assistant como dispositivo vinculado: guarda el **texto** de
tus conversaciones, **programa mensajes** desde una pantalla integrada y ofrece una
**API local** para automatizaciones y asistentes, con confirmación en el móvil.

- 💬 Archivo local y buscable de tus chats (solo texto).
- 🕒 Mensajes programados con vista previa del formato.
- 🔐 Envíos por API siempre confirmados; automatizaciones limitadas a una lista blanca.
- 📱 Botones **Enviar / Cancelar** en las notificaciones de la app de Home Assistant.

Consulta la pestaña **Documentación** de la App o [DOCS.md](DOCS.md).

> [!WARNING]
> Usa una implementación no oficial del protocolo de WhatsApp. No está afiliada a
> WhatsApp ni a Meta y su uso puede ir contra sus condiciones de servicio.
