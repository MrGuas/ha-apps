# Apps de casa para Home Assistant

Repositorio de Apps (complementos) para Home Assistant OS.

- **whatsapp_puente** — guarda el texto de las conversaciones de WhatsApp (whatsmeow + SQLite) y ofrece una API local para que Home Assistant pueda leer, buscar y (opcionalmente) enviar a una lista blanca de destinos.

Añadir en Home Assistant: *Ajustes → Apps → Tienda → ⋮ → Repositorios →* `https://github.com/MrGuas/ha-apps`
